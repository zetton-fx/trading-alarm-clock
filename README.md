# Trading Alarm Clock

トレーダー向けに設計された、カスタマイズ可能なデジタル時計とアラーム機能を備えたデスクトップアプリです。

## 主な機能

### **デジタル時計**
- カスタマイズ可能なフォント・色・サイズ
- 日付表示のON/OFF切り替え
- 常に前面表示対応
- 5段階の時計サイズ変更

### **アラーム機能**
- **メインアラーム**: 指定時刻にアラーム通知
- **先行アラーム**: メインアラームの数分前に事前通知
- **一括登録**: 経済指標サイトからのテキスト一括インポート
- **自動停止設定**: アラームの自動停止をON/OFF可能
- **アラーム重複処理**: 新しいアラームが古いアラームを自動的に上書き

### **音声設定**
- 5種類のアラーム音から選択可能
- メインアラーム・先行アラーム別々の音声設定
- ボリューム調整（0-100%）
- 音声プレビュー機能

### **高度な設定**
- **自動停止**: メインアラーム（30秒後）、先行アラーム（15秒後）の自動停止をそれぞれ設定可能
- **オフセット調整**: アラーム時刻の数秒前に鳴らすタイミング調整
- **自動有効化**: アラーム追加時の自動ON設定

## Docker環境での実行

### 前提条件

- Docker & Docker Compose
- X11転送対応（Linuxホスト）

### セットアップ手順

1. **ホストマシンでX11アクセス許可を設定**
   ```bash
   xhost +local:
   ```

2. **Dockerコンテナを起動**
   ```bash
   docker compose run --rm trading-alarm-clock bash
   ```

3. **コンテナ内でdbusサービスを開始**
   ```bash
   sudo service dbus start
   ```

4. **npm ライブラリをインストール**
   ```bash
   npm install
   ```

5. **プロジェクトをビルド**
   ```bash
   npm run build
   ```

6. **開発環境用のアプリを起動**
   ```bash
   npm run dev
   ```

## デバッグ機能

アプリケーションには開発者向けのデバッグ機能が組み込まれています。

### Developer Toolsの開き方

1. アプリケーションを起動
2. `Ctrl+Shift+I` (Linux/Windows) または `Cmd+Option+I` (Mac) でDeveloper Toolsを開く
3. Consoleタブを選択

### デバッグ関数

Developer ToolsのConsoleから以下の関数を実行できます：

#### **`debugShowSettings()`**
全設定を一覧表示します。メインプロセス（実際に使用される設定）とレンダラープロセス（UI表示用の設定）の両方を確認できます。

```javascript
debugShowSettings()
```

#### **`debugShowAlarmSettings()`**
アラーム設定のみを詳細表示します。

```javascript
debugShowAlarmSettings()
```

**表示内容：**
- グローバルアラーム音ファイル名
- グローバル先行アラーム音ファイル名
- ボリューム設定（%表示）
- **自動停止設定**（メインアラーム・先行アラーム）
- 登録済みアラーム数

#### 📱 **`debugShowAppSettings()`**
アプリ設定のみを詳細表示します。

```javascript
debugShowAppSettings()
```

**表示内容：**
- サイズ設定
- 常に前面表示フラグ
- フォント設定
- 色設定（文字色・背景色）

#### ❓ **`debugHelp()`**
利用可能なデバッグ関数の一覧を表示します。

```javascript
debugHelp()
```

### デバッグのユースケース

1. **アラーム音が変わらない場合**
   ```javascript
   debugShowAlarmSettings()
   ```
   メインプロセスとレンダラープロセスの設定が同期されているか確認

2. **設定変更が反映されない場合**
   ```javascript
   debugShowSettings()
   ```
   実際に使用されている設定値を確認

3. **メモリ上の設定確認**
   各設定がメモリに正しくロードされているかを確認

### 注意事項

- デバッグ関数はアプリ起動時に自動で登録されます
- 本番環境でも利用可能ですが、開発・デバッグ目的での使用を推奨します
- 設定変更後は該当するデバッグ関数で変更が反映されているか確認できます

## アラーム機能の詳細

### 🔄 **アラーム重複時の動作**

複数のアラームが同時に発動した場合、以下のルールで処理されます：

- **新しいアラームが常に優先**されます
- 種類（メインアラーム・先行アラーム）に関係なく、後から発動したアラームが前のアラームを上書きします
- 古いアラームの音声は自動的に停止され、新しいアラームの音声が再生されます

**例：**
```
21:25 先行アラーム「EUR/USD指標」開始
21:27 先行アラーム「GBP/USD指標」発動 → 前の先行アラームを停止、新しい先行アラームを開始
21:30 メインアラーム「EUR/USD指標」発動 → 先行アラームを停止、メインアラームを開始
```

### ⏰ **自動停止機能**

アラーム設定で以下の自動停止を個別に設定できます：

#### **メインアラーム自動停止**
- **ON（デフォルト）**: 30秒後に自動でアラームとポップアップを停止
- **OFF**: OKボタンまたはESCキーが押されるまで継続

#### **先行アラーム自動停止**  
- **ON（デフォルト）**: 15秒後に自動でアラームとポップアップを停止
- **OFF**: OKボタンまたはESCキーが押されるまで継続

### 🎹 **手動停止方法**

アラーム実行中は以下の方法で手動停止できます：
- **OKボタン**をクリック
- **ESCキー**を押す
- 自動停止がONの場合は指定時間後に自動停止
